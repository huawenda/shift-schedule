## 1. 背景与目标

### 1.1 现状（为什么必须重来）

| 位置 | 写死的内容 |
| --- | --- |
| `src/core/data/schedule.ts` | 13 个姓名、班组 4F–4X、24 天循环、锚点 `2026-06-07`、区间 `2026-04-19 ~ 2026-12-19` |

| `appConstants.ts` | `defaultCurrentUserName = '华文达'` |
| `services/backup.ts` | 备份只有日覆盖记录，没有「有哪些人」这件事 |

这五处互相咬合，单点改造会做出半成品，所以整层重做。

### 1.2 目标

- 分发即用：别人拿到静态包或 exe，**3 步向导**就能建好自己的排班表。
- 规律不动：4F–4X 的 24 天循环直接照搬，用户没有编辑入口。
- 人员自由：名字、人数、谁挂哪条班序，用户说了算；同一班序可以挂多人。
- 界面是「工具」而不是「某个人的表」：带 dashboard 外壳，为后续统计页留位。

### 1.3 非目标（第一版明确不做）

统计页 · 薪资计算 · 加班小时 · 法定标记 · 事假半天/一天 · 多套排班表 · 移动端适配 · 云同步 · 账号与权限 · 节假日/农历标注（保留但不强调）。

### 1.4 成功判据

> 一个没看过这个项目的人，在不看说明的情况下，5 分钟内建好自己的排班表，并成功改一次班。

## 2. 核心模型

### 2.1 班序模板 Pattern —— 固定，不可编辑

- 内置 **13 条**模板，ID 沿用 `4F` … `4X`。
- 每条 = 24 天班次数组（`白班/夜班/休息/白特/夜特/事假`）+ 全局锚点 `2026-06-07`。
- **不可增删、不可改周期长度、不可改序列**。没有编辑入口，只在向导和设置里被"选择"。
- 模板本身不含任何姓名。

### 2.2 成员 Member

```ts
interface Member {
  id: string        // 稳定 ID（nanoid 或时间戳+随机）
  name: string      // 用户自定义姓名，表内唯一
  patternId: string // 4F…4X
  label?: string    // 可选：对该班序的本地叫法，如"甲组"（见 §9 第 3 条）
}
```

- **人数不限**（1–N）。
- **同一 `patternId` 可挂多人**，这些人每天的班次完全一致。
- `name` 表内唯一 —— 否则覆盖记录会串人，向导与设置都要拦。
- **`id` 不可变**：改名、换班序都不换 id，保证历史覆盖记录不丢。

### 2.3 结算月

- 周期固定「上月 20 日 ~ 本月 19 日」，**不提供配置**（与现有使用习惯一致）。
- 月份可无限前后翻（`2025-05` … `2030-12` 都能到）。
- **不再预生成 244 天**：改成按需推算——给定月份，现算这一期里每人每天的班次（一期 30 或 31 天，取决于月份）。这是本次唯一必要的算法改动。

### 2.4 覆盖记录 Override

```ts
interface DayOverride {
  memberId: string  // 不是姓名
  date: string      // '2026-10-24'
  shift: ShiftType  // 只存"与模板不同"的那一天
}
```

- 只存与模板不一致的日子；**恢复默认 = 删除该条**，不写空值。
- 第一版只有班次一种覆盖（无加班、无法定、无事假时长）。
- 用 `memberId` 做键：改名不丢记录；删成员时一并清理其覆盖记录。

## 3. 信息架构（PC 专用）

运行环境确定为**公司办公 PC 大屏**，因此：

- 不做移动端布局，不做触摸优化。
- 设计基准 `1440×900`；**最低可用宽度 1280**；1366×768 的机器必须不塌（矩阵内部横向滚动兜底）。
- 不做响应式断点降级，只保证不溢出。

### 3.1 外壳

```
┌───────────────┬────────────────────────────────────────────────┐
│ 倒班表  (字标) │  2026 年 10 月  ◀  ▶   今天   导出   ⚙ 设置     │ 48px 顶栏
├───────────────┼────────────────────────────────────────────────┤
│ 排班           │  ┌──────────────────────────────────────────┐  │
│ 统计  (置灰)   │  │ 今日白班 4 人 │ 夜班 5 人 │ 休息 4 人 │ 出勤 9 人 │ 概览条
│               │  └──────────────────────────────────────────┘  │
│               │  ┌──────────────────────────────────────────┐  │
│               │  │  全员矩阵 / 个人日历（右上角切换）          │  │
│  ⚙ 设置        │  └──────────────────────────────────────────┘  │
│  v1.0         │                                                │
└───────────────┴────────────────────────────────────────────────┘
   228px 侧栏            白色画布（inset 8px）
```

- 侧栏与顶栏共用一块 tinted 底（`#f9fbfc`），**两者之间没有分隔线**，形成 L 形。
- 页面是白色画布，距窗口右、下各缩进 8px，圆角 16，1px 边，**无阴影**。
- 侧栏导航：`排班`（当前，2px 墨色下划线）/ `统计`（置灰不可点，tooltip「下一版」）/ 底部 `设置` + 版本号。

### 3.2 概览条（dashboard 感的来源）

一个容器，用 1px 分隔线切成 4 格：

| 格 | 内容 |
| --- | --- |
| 今日白班 | `4` 人（14px 标签 + 24px 数字） |
| 今日夜班 | `5` 人 |
| 今日休息 | `4` 人 |
| 今日出勤 | `9` 人（白 + 夜 + 特） |

- 全部按**当前查看的月份视图里的"今天"**统计；今天不在该月范围内时，整条显示灰色 `—` 并注明「今天不在本期」。
- 只数人，不算工时、不算钱。

### 3.3 画布主区（v1.0 修订）

> **实现时改了方案。** 原计划「左侧 340px 日历 + 右侧矩阵」并排，但算宽不够：
> 340 + 姓名列 148 + 30 列 × 24 + 侧栏 228 + 内边距 48 ≈ **1484px > 1440**。
> 压到 20px 列宽又会让「白特 / 夜特」放不下，只能牺牲可读性。
> 改为**同一位置切换两种视图**，各自占满画布宽度：
>
> | 视图 | 布局 | 用途 |
> | --- | --- | --- |
> | 全员矩阵（默认） | 姓名列 148px + 30/31 天列，列宽 `minmax(22px, 1fr)` | 看全组、点格子改班 |
> | 个人日历 | 7 列 × 5–6 行，格内含班次块 + 农历/节日角标 | 看某一个人的整月 |

- 1440 宽下矩阵列宽约 33px，1280 宽约 28px，都不需要横向滚动；再窄才交给矩阵内部横滚。
- 今天列用 1.5px `--accent` 内框，并追加在列头下方 2px 强调线；改过的日子右上角一个小圆点。
- 点矩阵任意格子 = 改那个人的那天；点日历格子 = 改当前选中成员的那天。
- 视图切换是分段控件（`全员矩阵` / `个人日历`），选择记在 state 里，刷新回到默认的矩阵。

## 4. 页面与流程

### 4.1 首次打开：3 步向导

| 步 | 内容 | 校验 |
| --- | --- | --- |
| 1 | 四条说明（班序固定 / 人员自由 / 随时改班 / 数据在本机）+ 「下一步」 | — |
| 2 | 成员表：每行 `姓名` + `班序` 下拉（4F…4X）+ `别名` + 删除；「添加成员」 | 姓名非空、表内不重名、至少 1 人 |
| 3 | 确认：列出「姓名 · 班序」+ 「进入排班表」 | — |

- 第 2 步预填 3 行空行，降低"从零开始的恐惧"。
- 向导可跳过 → 落到排班页并显示空状态（「还没有成员，去设置里添加」+ 一个按钮）。
- 向导只在成员数为 0 时出现。

### 4.2 排班页操作

| 操作 | 行为 |
| --- | --- |
| 切月 | 顶栏 ◀ ▶；「回到本期」按钮跳回当前结算月 |
| 切换查看对象 | 点矩阵里的姓名，或在日历视图顶部的下拉里选 |
| 改班 | 点格子 → 弹层选 6 个班次之一 → 保存；或「恢复默认」 |
| 关闭弹层 | `Esc` / 点遮罩 / 点关闭 |

- 改班弹层：居中 420px 白面板，班次用 6 个色块选项（文字 + 色），当前值带 2px 墨框；底部「恢复默认 / 取消 / 保存」。
- 保存后文案回到顶栏状态区（`已保存：白特`），不再做格子闪烁。

### 4.3 设置页

分左右两栏（左标签列 450px + 右面板 700px），三节：

1. **成员**：表格（姓名可改 / 班序可换 / 删除）。删除时提示「将同时删除该成员 N 天的改班记录」，需二次确认。
2. **备份**：导出 JSON / 导入 JSON（覆盖前确认）。
3. **危险区**：清空全部数据（输入"清空"才可点）。

## 5. 视觉规范（framed-sheet · seed 1324561339）

### 5.0 视觉基调：强制浅色（硬约束，不可协商）

运行环境是**公司办公 PC**，显示器色彩与对比表现有限，深色系观感差。因此：

- **只做浅色，不做暗色主题**，也不做"跟随系统"。
- 根节点强制 `color-scheme: light`，避免系统处于暗色模式时把原生控件（滚动条、输入框、下拉面板）染黑。
- **不写** `@media (prefers-color-scheme: dark)` 分支，任何组件都不得自带暗色变体。
- 画布 `#f9fbfc` + 白色画布 + 墨色文字 `#131416`，正文对比度全部 ≥ 4.5:1。
- 抽签方向 `framed-sheet` 本身即浅色方向，与本约束一致，无需重抽。

### 5.1 令牌

```css
:root {
  color-scheme: light;
  --ground: #f9fbfc;   --surface: #ffffff;  --raised: #f4f6f8;
  --active: #ebedee;   --border: #e8eaec;   --rule: #f0f1f2;
  --control: #cdced1;  --text: #131416;     --muted: #5d5f60;
  --accent: #1b6c80;
  --chart-1: #1b6c80;  --chart-2: #2f70bb;  --chart-3: #a86f0c;
  --radius-card: 8px;  --radius-control: 6px; --radius-sheet: 16px;
  --sheet-inset: 8px;  --sidebar-width: 228px; --topbar-height: 48px;
  --gap: 24px;  --pad: 24px;  --row-height: 48px; --control-height: 32px;
  --fs-title: 22px; --fs-section: 16px; --fs-kpi: 28px; --fs-body: 14px; --fs-small: 12px;
}
```

### 5.2 字体（离线约束下的取舍）

抽签给的是 IBM Plex Sans + Plex Mono，但**本地版必须 `file://` 离线可用、不加载网络字体**。
决策：**用系统 UI 栈**，保留抽签的字号/字重层级。

```css
font-family: "Segoe UI", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
```

- 字重：400 / 500 / 600，KPI 数字用 400、标签用 500。
- 所有会变的数字加 `font-variant-numeric: tabular-nums`。
- 数字列右对齐；矩阵列头日期居中。

### 5.3 班次色（6 种，写死）

| 班次 | 底色 | 文字 | 说明 |
| --- | --- | --- | --- |
| 白班 | `#dff3ff` | `#02689f` | 保留原色 |
| 夜班 | `#e3eaf3` | `#1e3a5f` | **已定**：去掉原来的紫 `#eee9ff`，改深蓝墨 |
| 休息 | `#dcfce7` | `#047857` | 保留原色 |
| 白特 | `#fff0c2` | `#b45309` | 保留原色 |
| 夜特 | `#fde7c7` | `#9a3412` | 保留原色 |
| 事假 | `#e5e7eb` | `#475467` | 保留原色 |

- **颜色永远配文字**，不允许靠色块单独表意。
- 概览条只统计 白/夜/休/特，事假单列在矩阵里。
- 六个色块全部在浅底上取；深色背景上一律不用这套色（本版没有深色背景）。

### 5.4 硬性禁止（会被检查）

渐变 · 光晕 · 玻璃拟态 · 带色圆底的图标 · KPI 上的迷你折线 · 彩虹图 · 卡片投影（弹层除外）· 紫色/靛色作品牌色 · 12px 以下文字 · 表格斑马纹 · **暗色主题 / 跟随系统暗色**。

### 5.5 密度

- 一个 gap 值（24px）横向纵向统一；内容内边距 24px。
- 矩阵行高 40px（含 2px 分隔线），姓名列与日期列各自显式高度，避免累积错位。
- 卡片边框不得比画布边更重。

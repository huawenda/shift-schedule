# 值班白板 · 小程序 UI 重设计方案

日期：2026-10-24
范围：`apps/miniapp`（今日 / 月历 / 统计三页 + tabBar + 弹层）。web 端不动，令牌系统留有可推广性。
替换对象：现行 v2「冷灰底 + 白卡片 + 柔投影 + 品牌蓝」。

---

## 0. 设计立场

### 0.1 为什么推翻 v2

v2 是一套放在任何记账、待办、健康 App 上都成立的「现代 SaaS 卡片」语言：冷灰底、白圆角卡、两档柔投影、品牌蓝。它没有错，但它**没有来源**——和倒班这件事无关。用户每天在车间门口、值班室墙上看到的那种排班白板，才是这个产品真正的视觉母语：格线、大字、色块磁贴、隔几米能扫出「我今天什么班」。

### 0.2 一句话方向

**把整页做成一块日光灯下的排班白板：信息本身就是设计。**
没有卡片、没有柔投影、没有品牌蓝；结构靠粗细墨线（板框/表头/格线），状态靠六色磁贴，选中靠盖章（墨底白字），数字用等宽表格字对齐。

### 0.3 与三代视觉的谱系

| | v1（已废） | v2（现役，将被替换） | v3 值班白板 |
|---|---|---|---|
| 底 | 暖灰纸面 | 冷灰 + 白卡浮层 | **日光灯白，整页即板，无分层** |
| 线 | 1px 细线切割 | 不用线，靠投影分层 | **2px 墨线做结构 + 1px 浅线做格** |
| 班次色 | 深色实心块 | 浅底徽章（小面积） | **磁贴色块，允许大面积（hero 就是最大磁贴）** |
| 强调色 | 墨黑 | 品牌蓝 #2563eb | **墨与信号红，无品牌色** |
| 选中态 | 描边 | 蓝底白字 | **盖章：墨底白字 + 直角** |

### 0.4 反参照（明确不做）

- 不做暖米色「纸感」+ 陶土色 accent（v1 的路，也是当前最容易撞脸的 AI 默认脸）。
- 不做深底 + 单一荧光绿的「暗黑终端」脸。
- 不做 hairline 细线 + 零圆角 + 报刊密排——白板的线是**粗**的（马克笔画框），字是**大**的（隔几米看），不是报纸。
- 不做卡片 + 柔投影 + 圆角一统天下（v2 的路）。
- 细节禁用：ALL-CAPS 眉标、到处「A · B · C」中点串接（板头用分格而不是中点）、链接尾巴加「→」（时间区间 `20:00 → 次日 08:00` 里的箭头是功能符号，保留）。

## 1. 令牌系统（`styles/tokens.scss` 全量重写）

### 1.1 色板（6 个基础 + 6 个磁贴）

```scss
// —— 板面 ——
$board:    #F7F8F6;   // 日光灯白：整页唯一底色，无卡片分层
$grid:     #DDE0DB;   // 次级格线（1px 浅线）
$ink:      #17181A;   // 马克笔墨：结构线、主文字、印章、主按钮
$pencil:   #535855;   // 铅笔注：次级文字（板面上 ≥4.5:1）
$paper:    #FFFFFF;   // 提亮面：表头行、磁贴留白位
$red:      #C2372B;   // 信号红：法定加班、失败、扣款。全应用唯一的警示色

// —— 班次磁贴（色块上直接承载文字）——
$tile-day:    #E8A21A;  // 白班 · 黄，配墨字（安全标识语言）
$tile-night:  #3D4E85;  // 夜班 · 靛，配白字
$tile-rest:   #2F7D4F;  // 休息 · 绿，配白字
$tile-dayx:   #A05A12;  // 白特 · 棕，配白字
$tile-nightx: #2D3A6E;  // 夜特 · 深靛，配白字
$tile-leave:  #5F6B76;  // 事假 · 石板灰，配白字
```

规则：
- 班次色语义与 v2/web 完全一致（黄=白班、靛=夜班、绿=休、棕=白特、深靛=夜特、灰=事假），只换用法：从「浅底小徽章」升级为「实体磁贴色块」。老用户的色彩习惯零成本迁移。
- 磁贴配色对价：白字磁贴 ≥4.5:1，黄磁贴用墨字（≈9:1）。上表数值已按此校过，实施时再跑一遍对比度脚本微调。
- **加班标记回到 web 端语义**：平日加班 = 磁贴右上角白点（带 1px 墨描边，保证黄底可见），法定 = 红点。v2 的琥珀点随 v2 一起退役。

### 1.2 线与形

```scss
$rule-2: 2px solid $ink;     // 板框、区块分隔、表头线（马克笔画的主结构）
$rule-1: 1px solid $grid;    // 表格内部次级格线
$rule-today: 2.5px solid $ink; // 「圈今天」——白板上拿马克笔圈住今天
$r-tile: 3px;                // 磁贴圆角：实体磁贴的微圆角，全应用唯一的圆角
$shadow-stamp: 3px 3px 0 $ink; // 硬投影：只给弹层与主按钮（印章的压感），无柔影
$pad: 20px;                  // 版心（v2 是 16，白板要更空）
```

### 1.3 字

```scss
// 家族：系统栈，不引入中文 webfont（包体红线）。
// 数字对齐靠 font-variant-numeric: tabular-nums（iOS/Android 微信内核均支持），
// 显示级大数字可选内嵌 Oswald 数字子集（仅 0-9 与 : / ≈ 15KB base64，
// wx.loadFontFace global 注入，失败静默回退系统 Heavy——增强项，不是依赖）。
$font-num: 'Bahnschrift', 'DIN Alternate', -apple-system, 'PingFang SC', sans-serif;

// 板尺（display 级行高收紧到 1.05-1.15，像牌面）
// 巨 64/900 —— 翻页牌班次名
// 大 32/800 —— 倒计时数字、月历日期、月份标题
// 中 15/600 —— 表格数据、按钮
// 注 12/400 —— 辅助说明（$pencil）
```

### 1.4 按压与动效

- 按压态 = `translateY(1px)`（磁贴按进板面）或 `opacity .55`，遵守 R2 立的规矩：只改 transform/opacity，不动尺寸边距。hover-stay 80ms。
- 选中态 = 盖章：墨底白字、直角（弹层内磁贴可加 `-1.5deg` 微旋转，盖歪一点才是章；表内选中不旋转）。
- **全应用唯一的编排动效**：今日页翻页牌的班次名在页面首次显示时「落版」——90ms 内 `translateY(4px) → 0` + 淡入，一次即止。保存成功时保存按钮 120ms `scale(0.96) → 1` 盖章反馈。除此之外没有任何入场/悬浮动画。

## 2. 版式与页面设计

### 2.0 总版式

整页一块板：无卡片容器，区块之间用 `$rule-2` 墨线 + 上下 16px 空气分隔。顶部是**板头**（墨色横档），底部 tabBar 是**笔槽**（白底 + 顶部墨线）。所有内容左对齐（表格数字右对齐），不做居中排版。

## 3. 组件规格速查

| 组件 | v2 做法 | 白板做法 |
|---|---|---|
| 区块容器 | 白圆角卡 + 柔投影 | 无容器，$rule-2 墨线分隔 |
| 班次标记 | 浅底徽章 m-* | 磁贴色块 t-*（色上直接放字） |
| 选中态 | 品牌蓝底白字 | 盖章：墨底白字（弹层磁贴可 -1.5deg） |
| 今天标记 | 蓝色 inset 描边 | $rule-today 墨框圈格 / 矩阵竖墨条 |
| 进度条 | 圆角胶囊 | 刻度尺（1px 刻度 + 墨色填充） |
| 主按钮 | 品牌蓝胶囊 | 墨底白字直角方块 + 硬投影 |
| 次按钮 | 灰底胶囊 | 白底 1.5px 墨框直角 |
| 输入框 | 灰底圆角 | 白底 1.5px 墨框直角，数字右对齐 |
| 同步状态 | 白胶囊 + 彩点 | 板头内白/红点 + 白字（可点重试） |
| 按压反馈 | scale(0.94) | translateY(1px)（按进板面） |

## 4. 落地映射（改什么、不动什么）

### 4.1 改动文件

| 文件 | 动作 |
|---|---|
| `styles/tokens.scss` | 全量重写（§1 令牌；t-* 磁贴类替换 m-*/s-* 语义，appConstants 的 mark 类映射同步改） |
| `app.scss` | 全量重写（板头、$rule 分隔、磁贴、盖章、刻度尺、弹层、按钮、输入框、按压态；step-* 步进器重绘为白板样式） |
| `pages/today/index.scss` + `.tsx` | 重写样式；TSX 仅改类名与板头/刻度尺结构 |
| `pages/calendar/index.scss` | 重写（含矩阵时刻表样式） |
| `pages/stats/index.scss` | 重写（账本样式 + 千分位格式化逻辑） |
| `custom-tab-bar/index.scss` | 重写（笔槽） |
| `components/ShiftEditor.tsx` | 类名微调，结构不动 |
| `components/TeamMatrix.tsx` | 类名微调（t-* 磁贴），结构不动 |

### 4.2 明确不动

### 4.4 风险与预案

| 风险 | 预案 |
|---|---|
| Oswald 子集字体加载失败/慢 | 增强项非依赖：`wx.loadFontFace` 失败静默回退系统 Heavy，观感靠字号字重成立 |
| 磁贴色块大面积后观感过重 | 磁贴只出现在：hero（一块）、周带（10px 条）、日历格（12px 条）、矩阵（36×30 块）——都是数据位，不做装饰色块 |
| tabular-nums 在低端安卓失效 | 数字列已用固定列宽对齐（矩阵/账本右对齐），失效只影响字距不影响对齐 |
| 黄磁贴墨字 vs 白磁贴白字的记忆成本 | 磁贴上永远有班次字（白/夜/休/白特/夜特/事假），色彩只是加速器不是唯一通道 |

### 4.5 验收清单

- `pnpm verify:miniapp` 全绿；实机截图五张过目。
- 对比度：白字磁贴 ≥4.5:1、黄磁贴墨字 ≥4.5:1、$pencil 于 $board ≥4.5:1、红点于白 ≥3:1。
- 审计红线不回退：按姓名视图步进一致、按压只改 transform/opacity、层级 z-index 10/50/100、触控目标尺寸不缩水。
- 全仓库无 #2563eb（品牌蓝清零）、无柔投影、无圆角卡。

## 5. 一页纸总结

把「倒班表」做成它名字说的那块**表**：日光灯白的一块板，粗墨线分行，六色磁贴标班，今天的格子被圈出来，月底一页账本双线合实发。没有卡片没有柔影没有品牌蓝——车间白板长什么样，它就长什么样；只是这块板会倒数你下一班还有多久。

# 昼夜 · 小程序端视觉规范

这份文档只管 `miniapp-uni/`。桌面端的规范在根目录 [DESIGN.md](../DESIGN.md)。

**这一版是桌面「小屏 UI（≤639）」的一比一移植**：旧的「历书」小程序界面（rpx 体系、朱红方印、二级页）已整体弃用，为这套 UI 让路。两者是同一产品的两面，不是两套审美。

---

## 0. 当前阶段

**全量数据层 + 三个页面。**

```
miniapp-uni/
├─ src/pages/
│  ├─ overview/index.vue      # 月度概览（tab 1）
│  ├─ matrix/index.vue        # 全员矩阵（tab 2）
│  └─ settings/index.vue      # 设置（tab 3）
├─ src/components/
│  ├─ nav-bar.vue             # 深青顶栏 + 月份胶囊（含微信胶囊让位）
│  ├─ tab-bar.vue             # 深青底栏 + CSS 图标
│  ├─ today-plaque.vue        # 概览：值班牌
│  ├─ month-calendar.vue      # 概览：7 列月历
│  ├─ todo-card.vue           # 概览：待办便笺
│  ├─ stats-panels.vue        # 概览：四张统计卡
│  ├─ pattern-grid.vue        # 24 格班序网格（只读预览 / 编辑共用）
│  └─ day-editor.vue          # 改班抽屉（个人日历全量 / 矩阵只改班次）
├─ src/styles/tokens.scss / base.scss   # 在 App.vue 里非 scoped 引入 → app.wxss
├─ src/store/roster.ts        # 花名册 + 结算月，唯一数据入口（uni storage 落盘）
├─ src/data/*                 # 与桌面同源的纯数据层
├─ src/utils/app-frame.ts     # 状态栏 / 顶部栏 / 底栏 / 系统胶囊实测量
└─ src/pages.json / manifest.json
```

- 数据口径与桌面完全一致：改班、加班、法定、事假时长、夜班津贴、工资拆分都走 `src/data` 的纯函数。
- 本机第一次打开时灌入演示花名册（`src/data/seed.ts`）。
- 业务口径由根目录 `pnpm test`（vitest）覆盖；页面层由 `pnpm verify:miniapp-uni` 验编译产物。

## 1. 移植原则

1. **一律用 px，不用 rpx。** 桌面移动档的字号 / 间距 / 圆角都是固定 px；rpx 会按屏宽等比放大，375 与 430 上就和桌面不一致了。
2. **断点只留 ≤639 一档。** 小程序没有 1023 的中间档，所有尺寸直接取桌面 `@media (max-width: 639px)` 的值。
3. **外壳按桌面三行网格换算**：匿名顶栏 → 自绘 `nav-bar`（48px + 状态栏）；侧栏 + 底栏 → 只留 `tab-bar`（57px + 安全区）。
4. **能复用桌面结构就复用**：概览页画布 `padding: 12px`、卡片间距 `12px`、`canvas-title` 22px + 铭牌副标，与桌面同一套 class 名（`styles/base.scss`）。
5. **比桌面多出来的只有平台约束**（见 §5），不加任何新视觉语言。

## 2. 外壳

### 2.1 顶栏（`nav-bar`，自绘）

- 高度：`状态栏 + 48px`（`app-frame.navHeight`）；深青 `--chrome` 底，正文 `--chrome-muted`。
- 一级页：居中的月份胶囊，`‹ 2026 年 11 月 › ｜ 回到本月`，36px 高，胶囊底 `--chrome-raised`，1px `--chrome-line`。
- **微信系统胶囊不可隐藏**，所以胶囊右侧预留实测宽度（`uni.getMenuButtonBoundingClientRect`，H5 为 0，最小 16px）；≤370px 时压缩标题字距与「回到本月」的间距。
- 二级页：返回箭头（CSS 画）+ 标题；目前只在设置抽屉里以自绘抽屉代替，二级页路径已删除。

### 2.2 底栏（`tab-bar`）

- `57px + env(safe-area-inset-bottom)`；深青底，顶部 1px `--chrome-line`。
- 3 个等宽项（`flex: 1 1 0`，48px 高、2px 间隙），图标 18px 全用 view 拼（日历 / 矩阵 / 推子），文字 11px。
- 选中项：`--chrome-weak` 圆角块 + `--chrome-accent` 文字。
- 走 `uni.switchTab`：三个 tab 页只创建一次，之后复用。
- **H5 预览额外处理**：uni H5 不支持 `tabBar.custom`，会再画一条原生底栏压住自绘栏（只有文字、没有图标）。`base.scss` 里用 `/* #ifdef H5 */` 把它 `display:none`，该规则在 `app.wxss` 中被条件编译剥离。

## 4. 页面

### 4.1 月度概览（`pages/overview`）

与桌面 `OverviewScreen` 的 ≤639 档一一对应，顺序固定：

1. 页头：`月度概览`（22px / 600）+ 铭牌副标（区间 · 天数 · 本人 · 班序）。
2. **值班牌**（`today-plaque`）：深青两列 + 本月通栏；班次名、倒计时、本月六格计数、整期节奏条（按默认班次分组，组间 4px）。
   本月计数固定 **2 行 × 3 项**：白班 / 夜班 / 休息 / 白特 / 夜特 / 法定，**0 天也占位**，事假不在这里显示。
   跨零点夜班按「正在进行的班次」算：会把昨天的班次一并纳入扫描，00:00–08:00 仍显示「距下班」。
3. **月历**（`month-calendar`）：7 列网格，格间距 4px；每格是 **1px 细边 + 6px 圆角 + 白底**的小卡（与桌面圆角格同一套），周期外换成无边框灰底；
   格内顺序 `日期（有待办时数字下压一道 2px 短横）→ 农历 → 加班/事假 → 班次块`；法定 13px 绝对右上；今天用 1px 强调色边 + 1px 外扩描边。
4. **待办**（`todo-card`）：便笺六色、勾选划线；列表滚动上限 `40% 视口高`（桌面 `40dvh`）。
5. **统计**（`stats-panels`）：单列四卡——本月概览六格 / 加班分布 4–5 柱 / 薪资 / 每日明细（内部滚动 280px）。
6. 点任意日历格子 → `day-editor` 抽屉（见 §4.4）。

### 4.2 全员矩阵（`pages/matrix`）

- 页头 + `按班次 / 按姓名` 分段（32px 高，深色选中块）。
- **概览条**：深青三格（今日白班 / 夜班 / 休息），`min-height 88`、`padding 8 12`、数值 28px；姓名摘要一行省略；`查看名单 ›` 打开白色浮层——≤639 时浮层 `left/right: 0`，贴着整条概览条展开，名单滚动区 `min(人数 × 31, 38% 视口高)`；点浮层外任意处关闭。白特 / 夜特并入对应班次，名单里用「特」标出。
- **矩阵**：整块白板（`radius 12 + shadow-raised`），姓名列 88px 固定，日期区横向滚动。
  全部内容放在一个普通 `view` 里，用 CSS `overflow` 横纵滚动（不用 scroll-view）；表头 `sticky top`、姓名列 `sticky left`，
  不经过 JS 滚动同步，所以纵向滚动时姓名列、横向滚动时表头都不会抖。
  卡片高度固定为「概览条与图例之间的剩余空间」，行多时在卡片内部纵向滚动，**图例始终在底栏上方**。
  边界回弹已关闭：`overscroll-behavior: none` 作用在真正的滚动容器上，安卓 WebView 的边界拉伸也一并关掉；
  矩阵页在页面配置里加 `disableScroll: true`，避免页面橡皮筋与滚动链把回弹带出来。
  **一次手势只滚一个方向**：首次位移超过 8px 时按主方向锁定，把另一轴 `overflow` 置 `hidden`，松手恢复；
  不拦截原生滚动，因此不会出现行列同时斜滚，也不会引入逐帧跟手抖动。
  - 行高：表头 37、每行 37（内容 36 + 1px 线），姓名列与日期区共用同一套高度，逐行对齐。
  - 列宽：按班次 `22px`（日历里 30 天正好撑出横滚）；按姓名 `48px`（放得下 3–4 个汉字）。
  - 格子：直角 + 1px 列线，色块用「3px 内缩的药丸」——桌面是 `::before + z-index:-1`，小程序里换成 `padding 3px + 内块`，四边留白等宽、视觉一致。
  - 今天只标表头（底色微染 + 数字加重 + 底部 2px 色带），正文格子不画描边；
    「今天」按**工作日**算：本人夜班跨零点时 00:00–08:00 仍停在开始那天，概览条同一天统计。
  - 右缘渐隐 32px：滚动条已隐藏，它提示右边还有半个月；滚到头自动收掉。
  - 点姓名聚焦整行（浅青底 + 左侧 2px 强调线）；点日期表头聚焦整列（表头底部 2px 强调线），
    再点一次取消；行聚焦与列聚焦可同时存在。
  - 点格子开 `shift-editor`（只改班次）。
- 图例：6 个 12px 色块 + 全称。

### 4.3 设置（`pages/settings`）

页头 + `人员配置 / 个人资料` 分段；所有区块都是「标题（3px 强调竖条）+ 说明」在上、白卡面板在下：

- **人员配置**
  - 班序：内置 13 条 2 列 chips（代号 + 24 段缩略色条），点开在下方展开 24 格预览；自建班序行 = 名称 + 使用人数 + 色条 + `查看/编辑/删除`，点「查看」就地展开 24 格；「新建班序」进编辑抽屉。
  - 成员：两行卡片网格 `姓名(跨列) + 操作 / 班序 + 岗位`；本人行三格只读（姓名 + 本人徽章 / 班序 / 岗位）；`↑ ↓ 删除`，本人不可删；底部「保存成员设置」，改动前一直禁用；校验错误在面板内列出。
    排序模式：按住把手上下拖动（也可用 `↑ ↓`），**点「完成」直接落盘**；「取消」回滚到进入排序前的快照。
- **个人资料**
  - 本人：姓名 / 班序（点开班序选择抽屉）/ 岗位；保存时走 `validateSelf` + `selfImpact`，有记录或薪资要清空时先弹「更换本人？」确认。
  - 薪资：四项金额（右对齐 + 「元」后缀），单独保存。
  - 备份：导出 = 整体 JSON 复制到剪贴板；导入 = 读剪贴板并整体覆盖（含个人信息）。
  - 清空数据：输入「清空」二字才放行，再走系统确认框。

### 4.4 抽屉（≤639 统一贴底）

公共外观：遮罩 `rgba(15,20,24,.26)`、面板 `width 100%`、`max-height 88vh`、上圆角 16、`shadow-sheet`、底栏 `padding-bottom: 12 + env(safe-area-inset-bottom)`；关闭动作都在标题右侧。

- **day-editor（个人日历）**：标题 = 成员名，副标 = `M月D日 · 周X · 默认 班次`。
  - `班次 / 待办` 两页签。班次页：六格班次（3×2、42px）+ 加班卡（预设胶囊 + 小时输入）+ 法定卡（是/否）+ 事假时长（4h/8h）；改班次时把不支持的值原地清掉；白特/夜特必须记加班才能保存。
  - 待办页：输入 + 添加、便笺条目勾选/删除，**改动立即生效**；底栏只有「完成」。
  - 底栏：`恢复默认 / 取消 / 保存`；有未保存改动时先就地提示「继续编辑 / 放弃修改」。
- **day-editor（矩阵，mode=shift）**：只保留六格班次；原记录带加班/法定时，改成休息/事假会提示「一并清除，加班请在日历里录入」；保存写 `editShift`，恢复默认写 `null`。
- **pattern editor**：名称输入 + 24 格（两行各 12）+ 当前格说明 + 白/夜/休三档调色板（点一下填入并自动跳下一格）。
- **班序选择**：内置 / 自定义分组，2 列 chips，点选即回填。
- **删除班序**：列出会被连带删除的成员与改班记录，输入班序名才放行。
- **更换本人**：列出将清空的记录数、加班/法定条数、薪资项数。

## 5. 与桌面端的差异清单（平台约束）

1. **矩阵滚动不走 `scroll-view`。** 安卓端 `scroll-view` 的边界拉伸没有官方开关（`bounces` 只对 iOS 生效），
   所以改用 `view` + CSS `overflow`，`overscroll-behavior: none` 才能真正作用在滚动容器上；表头/姓名列仍用 `position: sticky`。
2. **页面滚动代替画布内滚动。** 概览的 40dvh 待办上限、每日明细 280px 是固定高度；其余内容随页面滚。
3. **系统胶囊。** 顶栏月份胶囊整体略左，右侧给微信胶囊留空（§2.1）。
4. **备份走剪贴板。** 小程序没有桌面端的目录选择 / `<input type=file>`；导出/导入都是一段 JSON 文本。
5. **H5 预览不是最终形态。** H5 会隐藏 uni 原生 tabBar；`capsuleInset = 0`；真机验收以微信开发者工具 / 手机为准。
6. **没有键盘与悬停。** 成员排序同时支持 `↑ ↓` 与按住把手拖拽（与桌面一致），其余悬停反馈在触屏上自然消失。
7. **无原生二级页。** 旧 `pages/{calendar,members,pattern}` 已删除，能力并入概览/设置与抽屉。

## 6. 验收

```bash
pnpm -C miniapp-uni type-check
pnpm -C miniapp-uni build:h5           # 390×844 截图对比桌面
pnpm -C miniapp-uni build:mp-weixin
pnpm verify:miniapp-uni                # 读产物：页面/组件/令牌/关键结构
```

移动端基准截图：**390 × 844**。对齐检查项：

- 概览条 `366 × 106.8`，三格等分；
- 矩阵日期列 `22 × 36`、行高 37、姓名列 88；
- 顶栏 48 + 状态栏、底栏 57 + 安全区；
- 所有页面 `document.scrollWidth === 390`（无横向溢出）。

# 昼夜 · 小程序端视觉规范

这份文档只管 `miniapp-uni/`。桌面端的规范在根目录 [DESIGN.md](../DESIGN.md)，两者是**同一产品的两面**，不是两套审美：

- 相同：色彩令牌、班次六色、「深框浅纸」的基调、卡片与线条的层级判断；
- 不同：尺寸（rpx）、外壳（导航栏 + tabBar 取代侧栏 + 顶栏）、信息密度（一屏只回答一个问题）。

桌面端的规范改了什么，这里要跟着改对应的一项；这里新增的只写「移动端独有」的东西，不复述桌面已经写清楚的取舍理由。

---

## 0. 当前阶段

**这一版只做前端，不接业务逻辑。**

页面数据全部来自 `src/utils/demo.js`（写死的 13 人、本月记录、待办、薪资），形状照 `Roster` 写。页面只做 `import demo → ref / computed`，不碰 `src/data` 的 store，不碰 storage。

目的：先把「好不好看、放不放得下」验完，再接数据层。接的时候把 `demo.js` 换成 store，UI 一行不改。

**工程形态**：Vue 3 + TS + Vite 的 uni-app 工程，编译目标 `mp-weixin`。

```
miniapp-uni/
├─ src/pages/{calendar,matrix,settings,overview,members,pattern}/index.vue
├─ src/components/nav-bar.vue / tab-bar.vue
├─ src/styles/tokens.scss / base.scss      # 在 App.vue 里非 scoped 引入，编成 app.wxss
├─ src/utils/demo.js / app-frame.ts
├─ src/pages.json / manifest.json
└─ vite.config.ts                          # alias: @data → ../src/data
```

- 数据层不进新工程：`src/data` 仍是唯一来源，通过 `@data` alias 直接引用，不再有 esbuild 产物。
- 业务口径由根目录 `pnpm test`（vitest）覆盖；页面层只验编译产物。

## 1. 设计主张

桌面的比喻是「贴在墙上的排班表 + 一层窗口框」；手机端的比喻是**口袋里的排班卡**。

三条推论：

1. **一屏只回答一个问题。** 日历页回答「我今天什么班、这个月怎么排」，矩阵页回答「今天谁在上班」，设置页回答「我是谁、这个应用存了什么」。
2. **拇指比鼠标粗。** 所有可点目标 ≥ 88rpx（44pt），相邻目标间距 ≥ 8rpx。
3. **没有第三层壳。** 桌面有侧栏 + 顶栏 + 画布，手机只留导航栏 + tabBar，中间就是纸。

深框浅纸保持不变：`#0e2228` 的导航栏与 tabBar 把白纸托起来。手机上这个明暗对比比桌面更强，读起来就是一个应用，而不是一张网页。

## 2. 外壳

### 2.1 导航栏（自绘）

`pages.json` 的 `globalStyle` 设 `navigationStyle: custom`，由 `src/components/nav-bar.vue` 自绘。

| 项 | 值 |
|---|---|
| 高度 | `frame.statusBarHeight`（`uni.getWindowInfo()`，见 `src/utils/app-frame.ts`） + 88rpx，以 px 写进模板的 `:style` |
| 底部 | 不加边框，靠色差与纸面相接 |
| 左 | 「昼夜」品牌字，36rpx（`--fs-section`），`--font-brand`（衬线），`--chrome-text` |
| 右 | **当前页的上下文动作**，24rpx，`--chrome-muted`，可点区 88rpx 见方 |
| 右侧留白 | `190rpx` —— 右上角是微信的系统胶囊（约 174rpx 宽），不留就会被压住 |

**导航栏不写页面标题。** 页面身份由 tabBar 承担，顶部只放品牌与动作（日历页「概览 ›」、矩阵页「今天」、设置页留空）。标题写在这里会与月份条、概览条打架。

**`navigationBarTextStyle` 不能改成 `black`。** `navigationStyle: custom` 只是把标题栏交给自己画，状态栏的时间 / 信号 / 电量仍由这个字段决定；导航栏底是墨黑 `#171512`，配黑字等于隐形。它和 `backgroundColor`（画布色 `#ede8de`）是两个互不相干的字段，别一起改。

### 2.2 tabBar（原生 tabBar 的 custom 模式 + 页内自绘）

`pages.json` 里配了 `tabBar.custom = true`，三个 tab 页注册在 `tabBar.list`；原生栏由 `src/custom-tab-bar/` 的空组件占位（微信要求这个目录存在，但它不渲染任何样式），真正的 UI 仍是页面内的 `src/components/tab-bar.vue`。

**为什么不用 `reLaunch`**：`reLaunch` 会销毁并重建页面，新 WebView 在样式生效前会空一帧，这一帧就是偶尔出现的「闪白」。配成 custom 模式后切页走 `uni.switchTab`，tab 页只在第一次进入时创建、之后复用同一份 WebView，不再重建。

| 项 | 值 |
|---|---|
| 高度 | 112rpx + 底部安全区，以 px 写进模板 `:style`（取 `frame.tabBarHeight`） |
| 底 | `--chrome`（组件内写死 `#171512`，见下方说明） |
| 项 | 3 个：日历 / 矩阵 / 设置，20rpx 文字 + 34rpx 图标 |
| 未选中 | `#867e6f` |
| 选中 | `#e8c58b`，图标与文字一起转色（图标用 `currentColor` 绘制） |

**图标用 `view` 拼，不放图片。** 日历＝圆角方框 + 表头横条，矩阵＝2×2 小方块，设置＝三条递减横线。墨黑底上的 16px 线性 png 会糊成灰点，几何块反而清楚，也不用为三个 tab 准备两套图。

**颜色与安全区仍然绕开常规写法**，原因写在这里，别再改回去：

- 颜色写死：mp-weixin 的自定义组件默认样式隔离，`page` 上的 CSS 变量不保证继承。写 `background: var(--chrome)` 有整条 tabBar 变透明的风险。四个值与 `styles/tokens.scss` 同源，改色时两处一起改。
- `env(safe-area-inset-bottom)` 在部分机型返回 0，tabBar 盖不住 home indicator，底部会露出一条浅色。改用 `src/utils/app-frame.ts` 里的 `screenHeight - safeArea.bottom`。
- **安卓上这个值也常常是 0**（`screenHeight === safeArea.bottom`），手势条区域照样存在。该条实测约 12px，`app-frame.ts` 对 0 做了 14px 兜底，`tabBarHeight` 与页面 `padding-bottom` 共用同一个数。宁可 tabBar 高一点，也不要底部露白。
- `pages.json` 的 `globalStyle.backgroundColor` / `backgroundColorTop` / `backgroundColorBottom` 必须和画布同色（`#ede8de`），不能用外壳色或留默认白：这三个值画的是页面 WebView 背后的原生窗口，页面首次创建时会露出那一帧。写白就是白闪，写外壳色就是黑闪。
- 页面不加入场动效（`.rise` 已删除）：页面首次创建时整页会先空一帧，任何动画都在放大这一帧。
- 同一 tab 的连点会连切两下，`tab-bar.vue` 里用 300ms 的 `switching` 闸门挡住第二次。

**选中态不需要跨组件同步**：`tab-bar` 的 `current` 由每个 tab 页写死（0 / 1 / 2），页面本身就是选中态的唯一来源。页面被 `switchTab` 缓存后这个写死值也不会过期，`custom-tab-bar` 的空组件不参与选中态。

## 3. 令牌

移动端令牌是**独立的一份**（`styles/tokens.scss`），不照搬桌面的 px 值。它在 `App.vue` 的非 scoped `<style>` 里引入，编成全局 `app.wxss`；页面样式写在各自的 `<style lang="scss" scoped>` 里。

| 类别 | 令牌 | 值 | 用途 |
|---|---|---|---|
| 字号 | `--fs-kpi` | 72rpx | 关键数字（今日班次、实发） |
| | `--fs-title` | 44rpx | 全屏页标题 |
| | `--fs-section` | 36rpx | 月份、分区标题 |
| | `--fs-body` | 30rpx | 正文、列表主行 |
| | `--fs-control` | 28rpx | 按钮、控件、格内班次字 |
| | `--fs-meta` | 24rpx | 说明、副行、日号 |
| | `--fs-micro` | 20rpx | 农历、角标、图例 |
| 间距 | `--gap-xs/sm/md/lg/xl` | 8 / 16 / 24 / 32 / 48rpx | 相邻 8 起步，块间距 24，分区 48 |
| 圆角 | `--radius-sub` | 8rpx | 标记、班次块 |
| | `--radius-control` | 12rpx | 按钮、输入、分段 |
| | `--radius-block` | 16rpx | 卡内嵌块、列表组 |
| | `--radius-card` | 24rpx | 纸面、今日卡 |
| | `--radius-sheet` | 32rpx | 抽屉顶部 |
| 投影 | `--shadow-card` | `0 3px 12px rgba(2,10,13,.06), 0 1px 3px rgba(2,10,13,.04)` | 卡片 |
| | `--shadow-sheet` | `0 -4px 16px rgba(2,10,13,.10)` | 抽屉 |

> 投影一律用 **px**：`box-shadow` 里的 rpx 在部分渲染器不换算，整条声明会被丢弃（见 §7 禁令 1）。

颜色**全部沿用桌面 `tokens.scss` 的值**（外壳深青、三级线、两级字、六班次色、加班橙、法定黄）。移动端只新增两个：

- `--chrome-weak`：`rgba(127, 210, 226, 0.14)`，深青底上的选中胶囊；
- `--text-inverse`：`#ffffff`，墨底按钮与分段选中。

> 桌面令牌里的 px 尺寸（如 `--matrix-name-width: 120px`）不进小程序，移动端一律用 rpx 重新定。

### 4.1 日历（tab 1）

```
[导航栏] 昼夜                                    概览 ›
─────────────────────────────────────────────
‹  2026 年 11 月  ›
10/20–11/19 · 31 天
┌───────────────────────────────────────────┐
│ 今天 · 11月1日 周日            20:00–08:00 │  深青反相卡
│ 夜班                          〔+2h 加班〕 │
│ ───────────────────────────────────────── │
│ 1 项待办                                  │
└───────────────────────────────────────────┘
 日    一    二    三    四    五    六        64rpx
┌────┬────┬────┬────┬────┬────┬────┐
│ 01 │ 02 │ 03 │ 04 │ 05 │ 06 │ 07 │   格 ≥96rpx
│    │    │    │    │    │    │    │   1px 细线
│ 夜 │ 夜 │ 夜 │ 休 │ 休 │ 夜 │ 夜 │   方印 36rpx
└────┴────┴────┴────┴────┴────┴────┘
 ─────────────────────────────────────────────
 +h 加班    法 法定    4h 事假
  18 出勤        5.5 加班        4 待办     页脚 108rpx
```

**尺寸**

| 项 | 值 |
|---|---|
| 页面左右边距 | 24rpx（纸面宽 702rpx） |
| 月份条 | 88rpx 命中区（钮视觉 64，只画箭头不铺底）+ 40rpx 副行 |
| 今日卡 | `--chrome` 底、`--radius-card`、padding 24，与月历间距 16 |
| 星期栏 | 64rpx，左右各 16rpx（与网格同宽） |
| 网格 | 左右各 16rpx，7 等分，格与格之间 1px `--border` 细线，外沿同款 |
| 格子 | 92 × `minmax(96rpx, 1fr)`，纸白底，日期等宽 + 班次方印 |
| 页脚 | 108rpx：图例行 28 + 间距 8 + 数字行 40 + 上下 16 |

**今日卡**是整页唯一的暗块，回答「我今天什么班」：

- 上排：`今天 · 11月1日 周日` 20rpx `--chrome-faint`；右侧班次时段 24rpx `--chrome-muted`（休息日没有时段，不显示）
- 中排：班次名 `--fs-kpi` 600 `--chrome-text` 独占一行；右栏竖排角标（加班 `--overtime-bg`、法定 `--warning-bg`），形成票根的两栏
- 脚部：只有待办数 20rpx `--chrome-muted`，与中排之间一道 `--chrome-line`；没有待办时整块脚隐藏
- 本期不含今天时整卡替换为「今天不在本期」的虚线空态

**网格是表格，不是贴纸墙**：整格铺班次色会让 35 个格子连成一堵彩墙，日号被压成注脚。现在只用 1px `--border` 细线分隔，日期等宽，班次收成一枚 36rpx 方印。线只负责定位：不铺底、不加凹槽、不投影，与矩阵的分隔线同一档。

**格子**四角锚定，位置定死、内容显隐不改布局：

1. 日号（左上）24rpx `--muted` 等宽；整月的数字成一条竖线
2. 法定（右上）20rpx `--warning-bg`「法」，至多一枚
3. 农历（左下）20rpx `--faint`，**只在节日、节气、初一、十五出现**；没有就留空，方印不跟着上下抖
4. 加班 / 事假（右下）20rpx：加班 `--overtime-bg`，事假空心描边。两者不会同一天出现，共用这个角，`v-if` / `v-else-if` 只渲染一个
5. 班次方印：36rpx，绝对居中（`top/left 50%` + 负 margin），整月对齐成一条竖列

| 状态 | 表现 |
|---|---|
| 今天 | **不换底色**（换掉就丢了班次信息），格子 `inset 0 0 0 1px var(--accent)` 描边 + 日号转朱红 600。不用 42rpx 实心方块：矮屏格高约 96rpx 时它会和居中的方印撞在一起 |
| 周期外 | 内容 `opacity: .35`（不铺灰底，格线保持整片统一） |
| 与模板不同 | 方印加 `inset 0 0 0 1px var(--shift-mark)`（夜班用 `--shift-mark-inverse`） |
| 事假 | 方印「假」+ 右下 `4h / 8h` 空心角标 |


**页脚收在纸里**：上一行是格子上的角标本身（同字号、同色、同圆角），下一行是这个月的三个结果（出勤 / 加班 / 待办），数字 `--fs-section` 600、标签 20rpx `--faint`，列间竖发丝线。页脚不再是一张飘在纸外的卡 —— 屏幕矮的时候整页滚动，底部永远是完整的纸。

**多设备**：纸张 `flex: 1` 撑满可视区，格行 `minmax(96rpx, 1fr)`（矮屏保底、高屏吃掉余量）。内容比屏高时纸张按最小高度撑开、整页滚动，不写死格高 —— 写死就会在矮屏上把页脚挤到 tabBar 底下。

**信息减法**：农历不是每天都有，只做「标记」，不做「日历说明书」。7 列 92rpx 里塞四样全量信息，读者要逐格辨认，等于没有层级。

### 4.2 矩阵（tab 2）

```
[导航栏] 昼夜                                       今天
─────────────────────────────────────────────
 今日      白班 8        夜班 3        休息 2        概览条
┌──────────┬─────────────────────────────────┐
│ 姓名      │ 20   21   22   23   24   25 …   │  表头 64rpx
├──────────┼─────────────────────────────────┤
│ 华文达 4F │  ▢    ▢    ▢    ▢    ▢    ▢    │
│ 张伟  4G  │  ▢    ▢    ▢    ▢    ▢    ▢    │  行 96rpx
└──────────┴─────────────────────────────────┘
 白  夜  休  白特  夜特  事假                       图例
```

| 项 | 值 |
|---|---|
| 姓名列 | 180rpx 固定，与内容列之间 `1px --border-strong`（唯一的结构竖线） |
| 日期列 | 56rpx，一屏约 10 天，横向滑动 |
| 行高 | 96rpx；表头 64rpx |
| 药丸 | 四边留 4rpx、`--radius-sub`，格内单字 20rpx |
| 今天 | **只标在表头**：`--accent-weak` 底 + 底部 2px `--accent` 带；正文格子不描边 |
| 右缘 | 32rpx 渐隐，滚到头自动消失 |

**姓名列 180rpx 的理由**：姓名是矩阵的索引，不能被截断。姓名与「本人」徽章挤同一行时，3 字名会被压成「华…」——所以姓名独占一行，徽章跟副行走。

结构：外层 `scroll-view` 竖向（13 行），内层左侧姓名列固定、右侧 `scroll-view` 横向。表头放在横向容器里随行一起横移。

交互：点格子 → 底部抽屉（六个班次，只改班次，不记加班）；点本人行 → toast「本人的班次要到日历里改」。

### 4.5 人员配置（二级页，`pages/members`）

**这是应用的入口**——没有成员与班序，日历与矩阵都是空的，所以它必须有完整的增删改，不能只做「查看」。

```
[导航栏] ‹ 返回        人员配置

 华文达   4F · PNP        〔本人〕
 张伟     4G · 班长
 李娜     4H
 ……                                       行 112rpx（两行）
 [ ＋ 添加成员 ]                            虚线按钮，88rpx 高
```

| 项 | 值 |
|---|---|
| 分段 | 与控件同高（68rpx），选中墨底白字；不用强调色 |
| 成员行 | 姓名 30rpx 600 + 副行「班序代号 · 岗位」20rpx `--faint`；右侧「本人」徽章（`--accent-weak` 底 + `--accent` 字，8rpx 圆角） |
| 班序行 | 代号 30rpx 600（等宽数字），右侧「内置 / N 人使用」20rpx `--faint` |
| 添加 | 虚线边框按钮（`--border` dashed + `--radius-block`），文字 `--muted` |

**成员编辑抽屉**（底部，全宽）：

- 姓名（输入）
- 岗位（输入，可空）

- 「设为本人」开关行
- 底部：删除成员（`--danger` 文字，仅此一人时禁用）/ 取消 / 保存

### 4.6 班序编辑（全屏页，`pages/pattern`）

24 天循环，**只有白班 / 夜班 / 休息**三种可选（白特、夜特、事假是单天的临时决定，不属于排班节奏）。

```
[导航栏] ‹ 班序                4F（内置只读）
```

## 5. 组件语言

| 组件 | 规则 |
|---|---|
| 纸面 | 白底、`--radius-card`、`--shadow-card`；一页最多一张 |
| 卡片 | 只用于「独立的一件事」（今日卡、矩阵、统计块）；同类的多张并列改成列表行 |
| 列表行 | 104rpx（单行）/ 112rpx（双行），分隔线内缩 32rpx |
| 主按钮 | 88rpx 高、`--radius-control`、墨底白字（`--text`） |
| 次按钮 | 同高，1px `--control` 描边、白底 |
| 虚线按钮 | 添加类动作专用：`1px dashed --border` + `--muted` 字 |
| 分段控件 | 68rpx 高，选中墨底白字；**不用强调色**（一页多处强调会互相抵消） |
| 抽屉 | 底部、`--radius-sheet` 顶、遮罩 `rgba(15,20,24,.26)`、`--shadow-sheet`、最大 88vh |
| 角标 | 20rpx，圆角 8rpx，内边距 `2rpx 6rpx`；加班橙 / 法定黄 / 事假灰三套，不再加第四种 |
| 徽章 | 「本人」专用，8rpx 圆角，浅青底墨青字；只表身份、不表状态 |
| 空态 | 虚线框 + 居中标题 + 说明 + 一个动作按钮；不用「一排灰字贴左上角」 |

## 6. 动效

| 场景 | 表现 |
|---|---|
| 页面进入 / tab 切换 | **没有动效**。`switchTab` 第一次创建页面时，任何动画都会在 WebView 首帧上留出一块空白，看着就是闪白 |
| 翻月 | 直接换内容，不做淡入 |
| 抽屉 | 直接出现 / 消失，不做位移 |
| 按下反馈 | `background: --active` 或 `opacity: .9`，不用缩放 |
| 开关 | 只给滑块 `transform` 120ms，属于状态反馈，不涉及页面进入 |

页面级动画一律不加；`styles/base.scss` 里不保留 keyframes。动效不是必需品，稳的静态界面比一次闪白更值。

## 7. 已知取舍与禁令

| 取舍 | 原因 |
|---|---|
| 不写页面标题在导航栏 | 与月份条、概览条打架；页面身份由 tabBar 承担 |
| tabBar 不用图标 | 深青底上的小线性图标糊成灰点，胶囊选中语言更统一 |
| 日历不显示全量农历 | 100rpx 宽的格子塞四样信息，层级全平，读者要逐格辨认 |
| 矩阵横向滚动、不转置 | 转置后看不到「某人整月连着上什么班」，而这是排班表的首要问题 |
| 班序编辑单独开全屏 | 抽屉里只露两行 24 格，点着会滑 |
| 人员配置必须完整 | 没有成员与班序时日历与矩阵都是空的，它不是「高级设置」而是入口 |
| 不接业务逻辑 | 当前阶段只验视觉；切换数据源时 UI 一行不改 |
| 页面对接导航/tabBar 用模板 `:style` 注入 `padding-top` / `padding-bottom` | 高度是运行时算出的 px（含状态栏、安全区），样式文件里写不了。**页面的 style 里一律不写 `padding` 简写**——它会与注入值打架，一旦顶部被覆盖，卡片就直接顶在顶栏上（概览页踩过） |
| scoped 样式与 `page` 选择器 | 页面级全局样式（设置 / 成员 / 班序的白纸底）必须写在**非 scoped** 的 `<style>` 块里；scoped 只作用于组件内部，产物里是 `.类名.data-v-…` |
| 原生 tabBar 只留 custom 模式，UI 仍页内自绘 | `pages.json` 配 `tabBar.custom = true`（`custom-tab-bar/` 为空占位），字段只用于声明哪些页是 tab 页。换来的是 `switchTab` 复用页面、切页不重建（不闪白）；代价是多了一个空组件目录，底栏样式仍要自己接管 |
| 日历页按可视高度自适应 | 纸张 `flex: 1` 撑满，格行 `minmax(96rpx, 1fr)`；矮屏保底、高屏吃掉余量。不要再写死格高：写死就会在矮屏上把页脚挤到 tabBar 底下。内容仍超出时整页滚动，不裁纸 |
| 日历不留纸外卡片 | 图例与本月的三个结果都收进纸内页脚。纸外再放一张卡，屏幕矮时永远是它先被 tabBar 压住 |

**六条禁令**

1. `box-shadow` 里**不写 `rpx`**——部分渲染器不换算，整条声明会被丢弃（今天格描边、弹层选中态都因此消失过，见根 DESIGN.md §6.4）。
2. 颜色、字号、圆角只取 `styles/tokens.scss`；出现十六进制色值或阶梯外字号即返工。
3. 可用目标不得小于 88rpx；同屏相邻可点元素间距不得小于 8rpx。
4. 不在格子里加第四种信息（待办点、改班点、状态点一律不加）。
5. 抽屉不套抽屉；需要第二层就开全屏页。
6. **不用 `+` / `~` 兄弟选择器做关键样式**——WXSS 里相邻兄弟选择器不生效，用它画分隔线会一条线都没有（设置页实测）。分隔线一律写在元素自身的 `border-bottom` 上。

另外两条实测环境事实，写代码时别再试：

- `wx.createSelectorQuery()` 的 `selectAll(...).fields({ computedStyle })` 在模拟器里可能不返回（`select` 单节点正常）；
- 开发者工具 Console 里 `console.log(对象)` 报 `An object could not be cloned`，查样式时用字符串拼接输出。

## 8. 验收

1. **不主动截图**：改动由用户实机验证后反馈（模拟器截图需先申请）。
2. 页面层只验编译产物：`pnpm miniapp:build && pnpm verify:miniapp-uni`（34 项结构断言，覆盖 app 配置、令牌、六页四件套、组件注册与关键结构）。验 dev 产物用 `node scripts/verify-miniapp-uni.mjs miniapp-uni/dist/dev/mp-weixin`。
3. 业务口径不进这个脚本：由根目录 `pnpm test`（vitest 覆盖 `src/data`）负责。
4. 读图时（用户发来的截图）检查四件事：**放不放得下**（是否溢出或留白过大）、**层级对不对**（第一眼落在预期位置）、**对比够不够**（20rpx 小字与灰线在缩略图上还能辨认）、**边界干不干净**（圆角裁切、渐隐、分隔线内缩）。
5. 只读相关的那一张，不为「全绿」跑全套检查。

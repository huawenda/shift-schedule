shadcn/ui 原生默认外观

6 类组件 + Card · new-york-v4 / Tailwind v4 / neutral 主题 · 未套昼夜 token

这一页是 shadcn 开箱即用的样子。所有尺寸、圆角、间距、阴影、配色都按官方组件源码的 className 与 neutral 主题变量还原， 源码由 pnpm dlx shadcn@latest view @shadcn/<item> 取得（registry/new-york-v4/ui/）。 这是纯 CSS 静态还原，不是 React 运行时；字体默认 Inter，本机未安装时回退系统字体。
全部组件默认展开可见，不需要点开。deep 差异对照见页尾；套上昼夜 token 后的复刻态在 design/shadcn-components-preview.html。

倒班表 · 本地版
================

这是一个纯本地的静态页面：不联网、不需要登录、没有账号和鉴权。
把这个文件夹整个拷到任何设备上就能用。

------------------------------
怎么打开
------------------------------

方式一（最简单）
  直接双击 index.html，用 Chrome / Edge 打开即可。
  页面里所有 JS、CSS、图标都已就地打包，file:// 下也能正常跑。

方式二（推荐，可装成 App）
  在本文件夹里起一个静态服务，例如：
      npx serve .
      或  python -m http.server 8080
  然后用浏览器访问提示的地址。
  用 Chrome / Edge 打开后，地址栏右侧会出现「安装」图标，
  点它就能像普通 App 一样装到桌面或手机主屏，带独立图标、全屏运行。

  iPhone / iPad 用 Safari 打开后，点「分享 → 添加到主屏幕」。

------------------------------
数据存在哪里
------------------------------

所有数据（排班改动、加班、法定、事假、薪资输入）都保存在
当前浏览器当前站点的 localStorage 里，也就是这台设备的这个浏览器中。

换一台设备、换一个浏览器、或者用无痕/隐私模式打开，看到的都是空数据——
它们之间不会自动同步，因为本来就没有服务器。

重要：清理浏览器数据 / 清除站点数据会把记录一起删掉。
      所以状态栏上提供了「导出备份」和「导入备份」。
      建议排完班就导出一份 JSON 存到网盘或 U 盘。

------------------------------
备份与恢复
------------------------------

导出备份
  点状态栏的「导出备份」，会下载一个
  「倒班表-本地备份-日期-时间.json」文件。换设备后带着这个文件即可。

导入备份
  点状态栏的「导入备份」，选中之前导出的 JSON。
  注意：导入会覆盖这台设备上现有的排班记录（会先弹窗确认）。
  薪资输入也会一起被覆盖。

------------------------------
关于本文件夹
------------------------------

index.html              入口页面
assets/app-*.js         全部逻辑（已打包，不需要联网）
assets/style-*.css      全部样式
icons/                  应用图标
manifest.webmanifest    安装到桌面用的清单
service-worker.js       安装后离线运行用（file:// 打开时不会注册）

这个文件夹是自包含的：不依赖 npm、node，也不依赖任何后端服务。
只要保留文件结构，放到哪个目录都能用。

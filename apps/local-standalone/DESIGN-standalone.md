# 倒班表 · 本地版 视觉规范

> 本文件是 **本应用专用**的视觉规范，**取代**根目录 `DESIGN.md` 对 `apps/local-standalone` 的约束。
> `DESIGN.md` 仍然适用于 `apps/web` 与 `apps/miniapp`；两者是不同产品线，规范互不覆盖。

---

## 0. 这个应用是什么

不是"排班管理系统的 Web 版"。它的实际身份是：

> **一台离线运行的个人仪表。** 没有服务器、没有账号，复制进任何设备就能跑，
> 数据只在自己的机器上。它服务一个人—— 那个人坐在桌前，对着一块
> 30 天 × 13 人的矩阵，回答三个问题：**我今天什么班、这个月我加了多久、这个月我该拿多少钱。**

三条推论，后面所有规则都从它们来：

1. **主体是矩阵，不是页面。** 403 个格子之间的对比，比任何一段文字都重要。
2. **几乎全部内容是数字和班次代码。** 人名和日期是标签，不是正文。
3. **没有协作。** 登录、角色、同步、冲突处理在这个应用里都不存在，不要为它们留位置。

## 1. 方向：石墨仪表盘（Graphite Instrument）

参照物是**墙上的磁排班板**和**值班室的仪表**，不是 SaaS 后台。
面板是中性的冷石墨，班次色是背光格。

### 1.1 核心规则

> **是班次，就有色；是界面，就是无彩色。**

这条规则取代常见的"单一命令色"。它比"蓝色是唯一命令色"更狠也更实用：
自动消灭按钮、标签、描边上的所有色相，让**班次色成为屏幕上唯一的有彩色信息**。
界面层级完全靠**亮度**（`face-0 → face-3`）和**发丝线**表达。

违反示例：给「导出」按钮上蓝色、给选中月份上蓝色描边、给卡片顶部加渐变色条。

### 1.2 记忆点：矩阵本身

**不需要额外的视觉装置。**

403 个自发光班次格 + 零圆角 + 发丝线直接对接 —— 这套几何本身就是够 distinctive 的。
它是墙上的磁排班板，不是数据看板。再往上加装置只会把它变成数据看板。

「今天」的定位**只由日期表头承担**：当天日期用 `--signal` 显示，并加一道 2px 白帽。

> 踩过两次坑：最初加了一条贯穿 13 行的竖线，又在日期表头左缘加了一条。
> 日期文字变白 + 2px 白帽已经足够定位，两条竖线都是重复信息，已全部移除。
> **一个视觉信号只说一件事，说两遍就是噪音。**

日历里今天保留一圈描边 —— 那是另一个视图，有自己的日期数字，不算重复。

改动某一格时，该格闪一次（`cell-confirm`），这是唯一的"回答用户动作"的动效。

| Token | 值 | 用途 |
|---|---|---|
| `--ink-hi` | `#e8edf2` | 主数据、人名 |
| `--ink` | `#aebac7` | 次级标签 |
| `--ink-lo` | `#7a8794` | 元信息、日期、轴 |

### 2.3 发光白（全站唯一强调色）

> 白色**只**说一件事的变体：当前 / 主操作 / 焦点。
> 任何新增的白色用法都要先对照这张表 —— 一个信号色只能有一个含义，
> 否则读图的人必须去查图例。

| Token | 值 | 只给这两处 |
|---|---|---|
| `--signal` | `#f2f7fa` | ① 今天的日期标记（表头文字 + 白帽、日历描边）② 主操作按钮与「实付工资」描边 ③ 焦点环 |

### 2.4 班次语义色

深底上做自发光填充。**每格必须同时带中文标签**，颜色不是唯一信息通道。

| 班次 | 填充 | 文字 |
|---|---|---|
| 白班 | `--day-fill` `#0f3a4a` | `#7fd4f0` |
| 夜班 | `--night-fill` `#241a47` | `#b9a6f5` |
| 休息 | `--rest-fill` `#10331f` | `#6fcb94` |
| 白特 | `--specday-fill` `#3a2a08` | `#e8b44a` |
| 夜特 | `--specnight-fill` `#3d1a0c` | `#f09a5e` |
| 事假 | `--leave-fill` `#23282e` | `#97a3ae` |
| 法定 | `--legal-fill` `#3f1416` | `#f58a8a` |

「休息」占比约三分之一（10/30 天），它的填充刻意压得很暗，
让色相主要只出现在文字上，避免矩阵被绿色淹没。

**零值不挂语义色。** `¥0.00` 用中性底（`.salary-readout.is-zero`），
不用法定红或扣款琥珀 —— 那是虚假强调。

## 3. 字体

### 3.1 硬约束：不加载任何网络字体

应用必须能在 `file://` 下离线运行，所以只能用系统字体。

### 3.2 两族，按语义分家

```css
--font-lang: "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei",
             "Noto Sans CJK SC", "Source Han Sans SC", system-ui, sans-serif;
--font-data: ui-monospace, "SF Mono", "Cascadia Mono", "DejaVu Sans Mono",
             Consolas, monospace;
```

**分家依据是语义，不是层级：这是班次板，不是杂志。**
11 个白班、9 个夜班、`¥12,845.50`、`10.5h` 全部是数据，
全部要能竖着对齐比较。所以：

- 凡是**数字** → `--font-data` + `font-variant-numeric: tabular-nums`
- 凡是**中文** → `--font-lang`

不要用"标题字体 vs 正文字体"这种装饰性分法。

### 3.3 字阶（固定值，不用流体）

| Token | 值 | 用途 |
|---|---|---|
| `--fs-display` | `28px` / 700 | 屏幕名「倒班表」 |
| `--fs-title` | `18px` / 650 | 区块标题 |
| `--fs-body` | `14px` / 400 | 说明文字 |
| `--fs-label` | `13px` / 600 | 字段名、表头 |
| `--fs-data-lg` | `24px` / 600 | 大数字 |
| `--fs-data` | `14px` / 500 | 格内内容、金额 |
| `--fs-data-sm` | `12px` / 500 | 日期、元信息 |

## 4. 圆角与阴影

| 元素 | 圆角 | 说明 |
|---|---|---|
| 排班格、日历格 | `0` | 发丝线直接对接，像物理排班板 |
| 控件 | `2px` | |
| 面板 / 弹层 | `2px` | |

## 5. 布局

### 5.1 桌面结构

```
┌────────────────────────────────────────────────────────────────┐
│ 倒班表 09/20–10/19   ◀ 10月 ▶     华文达 4F ▾   刷新 统计 导出 导入 │ 44px sticky
├────────────────────────────────────────────────────────────────┤
│ 11 白班   9 夜班   10 休息   0 白特   0 夜特   0 事假    本地模式 │ 40px
├───────────────────────┬────────────────────────────────────────┤
│ 排班日历        华文达 │ 排班表                [按班次|按姓名] │
│ ┌───┬───┬───┬───┬───┐ │ 姓名   20 21 22 23 24 25 ... 19          │
│ │日 │一 │二 │三 │四 │  │ │ 华文达 │夜 休 休 白 白 白 ... 白          │
│ │20│21│22│23│24│  │ │ │ 张舒棋 │夜 夜 休 休 白 白 ... 白          │
│ └───┴───┴───┴───┴───┘ │ …      │                                │
│                       │                                     │           │
└───────────────────────┴────────────────────────────────────────┘
          ↑ 今天的日期用白色标出，并加一道 2px 白帽
```

- **对齐**：全部左对齐；表格数字列右对齐。
- **sticky 只剩顶栏**（44px）。原版在 1280 宽下 sticky 高达 345px（占视口 43%），
  内容从底下穿过会被拦腰切断 —— 那是不可接受的。
- **面板不拉伸**：只有 13 行时，让矩阵撑满 1200px 高的显示器会得到松垮的空气行，
  而 stretch 之后面板内部会出现一大块"空的面板"，比留白更糟。面板按内容高度，多余空间留作画布。
- **汇总是一行内联统计**，不是 6 个磁贴。
- **月份用步进器**（`◀ 10月 ▶`），不是 8 个铺满全宽的 tab。
- **日历与排班表是同一矩阵的两种缩放**：日历格显示「日 + 农历 + 班次色条」，
  表格格显示「班次文字」。同一个格子几何，两种信息密度。

### 5.2 列宽必须用 `minmax(下限, 1fr)`

```scss
grid-auto-columns: minmax(var(--cell-w), 1fr);   /* 不是 var(--cell-w) */
width: 100%;                                     /* 不是 min-width: max-content */
```

- 容器够宽 → `1fr` 把余量均分，表格填满，不会右侧空一大块；
- 容器不够宽 → 轨道被下限顶住，grid 溢出，交给 `.matrix-scroll` 横滚。

行与表头都取 `width: 100%` 而不是 `min-width: max-content`，
保证各行拿到完全相同的宽度，各自算出的 `1fr` 结果一致，
表头与数据行才逐列对齐（有断言校验）。

> 踩过一次坑：用定值 `var(--cell-w)` 时，1920 下多出 576px 空白、
> 3440 下多出 1698px。`screenshot-dist.mjs` 的「可见天数」会打印成
> `55/30` —— 这个荒谬的读数就是症状。

### 5.3 断点

| 区间 | 列宽下限 | 行高 | 侧栏 |
|---|---|---|---|
| `≥2100px` | 56px（实际约 96px） | 34px | 380px |
| `1600–2099` | 44px（实际约 67px） | 30px | 320px |
| `1280–1599` | 40px | 28px | 320px |
| `1024–1279` | 40px，姓名轨 100px | 28px | 268px |
| `≤1023` | 40px | 28px | 两栏堆叠 |
| `≤767` | 40px，姓名轨 88px | 28px | 汇总行横滚 |

括号内是 `1fr` 均分后的**实际**列宽。`≥1920px` 起一屏看完整月。

**列宽下限 40px 是硬要求**，不是随手取的数：格子里是「白班」或「华文达」
这类 2~3 字标签，3 个汉字 × 12px = 36px，40px 刚好留 4px 余量。
`.roster-cell` 同时带 `white-space: nowrap` —— 宁可横向滚动也绝不允许折行，
折行会把行高撑高，整张表参差。

**不砍字**：显示「文达」而不是「华文达」是信息损失，比字小一点糟得多。
`screenshot-dist.mjs` 对「按姓名」视图有独立溢出断言。

## 6. 状态与反馈

- **空状态**：说明"现在没什么"**并给出下一步动作**，不画一副没有数据的图。
  见 `.empty`。
- **加载中**：文案以 `…` 结尾（`读取中…`、`保存中…`）。
- **保存确认**：改动的那一格闪一次（回答用户动作的动效，不是装饰）。
- **动效克制**：只保留两处 —— 弹层入场 140ms、格子确认 420ms。
  全部尊重 `prefers-reduced-motion`。

## 7. 无障碍基线

这些是硬性要求，不是可选项：

| 项 | 要求 |
|---|---|
| 焦点可见 | 全局 `:focus-visible` 兜底 + 2px `--signal` 描边；禁止裸 `outline: none` |
| 弹层 | Escape 关闭、焦点陷阱、关闭后焦点归还触发元素（`useDialog`）|
| 语义标签 | 动作一律 `<button>`；表单控件有包裹式 `<label>` |
| 对比度 | 正文 ≥ 4.5:1，大字 ≥ 3:1 |
| 不靠颜色 | 班次格必带中文标签；今天有白色日期 + 白帽 |
| 触控目标 | 关键控件 ≥ 44px |
| 状态朗读 | 错误条 `role="alert"` |
| 数字格式 | 金额/日期走 `Intl`，禁止 `toFixed` 硬编码 |
| 数字对齐 | 所有数字 `tabular-nums` |
| 状态入 URL | 月份与人员进 query（`#/schedule?month=10&person=...`），可深链、可刷新 |
| PC 可选中 | `(hover: hover) and (pointer: fine)` 下放开 `user-select`，便于复制工时和金额；控件本身仍禁选 |

## 8. 反面清单

不要做这些事：

- 给界面元素（按钮、标签、描边、选中态）加色相 —— 违反 §1.1
- 用 `border-radius: 999px` 药丸
- 用装饰性渐变（任何渐变都不属于这套系统）
- **用定值列宽**（`grid-auto-columns: var(--cell-w)`）—— 宽屏会空出一大片
- **用 `--signal` 表示「有加班」** —— 白色已被「今天/主操作/焦点」占用
- **在已经标了今天的地方再叠一层标记**（表头已标，就别再画竖线）
- **让标签折行**（`.roster-cell` 必须 `nowrap`，列宽不够就该横滚）
- **柱形图所在的 grid item 设 `justify-items: center`** —— 第一行 wrapper 会收缩成 0 宽，柱子直接消失
- 为了塞进更多列而**砍掉文字**（显示「文达」不如把字号降到 10px）
- 给零值挂语义色
- 画一副没有数据的图表
- 加载网络字体（会破坏 `file://` 离线可用性）
- 用 `toFixed` 拼金额（没有千分位）
- 为了塞进更多列而缩小字号（应该横滚或换布局）
- 把这套规则回灌到 `apps/web`（那是另一个产品线）

## 9. 代码位置

```
src/styles/
  01-tokens.scss       颜色、字体、字阶、圆角、间距、班次语义、重置、动效
  02-shell.scss        顶栏、汇总行、面板基座、控件、分段控件、空状态
  03-matrix.scss       左栏日历、右栏排班表、今天标记、图例
  04-stats.scss        统计页：概览、柱状图、薪资、每日明细
  05-overlays.scss     弹层、字段、班次选项、选择器
  06-responsive.scss   断点与 hover 能力适配
```

层序即优先级：后面的文件覆盖前面的同名规则。
新增样式请放进语义正确的那一层，不要新建 `13-*` 补丁文件。

## 10. 改动后必须跑

```bash
pnpm typecheck
pnpm test
pnpm build
node scripts/verify-dist.mjs     # 32 项，http + file:// 双场景端到端
node scripts/screenshot-dist.mjs # 8 个分辨率的布局硬性检查
```

`verify-dist.mjs` 和 `screenshot-dist.mjs` 里的选择器与本文件的 DOM 结构强耦合。
**改动 `ScheduleView` / `StatsView` / `AppChrome` 的类名时，必须同步更新这两个脚本**，
否则回归会静默失效（历史上已经因此挂过两次）。

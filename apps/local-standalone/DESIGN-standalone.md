# 昼夜 · 个人倒班记录本 视觉规范

> 本文件描述 `apps/local-standalone` 的视觉体系。
> 2026-10 起，本地版的界面**与 `apps/web` 共用同一套设计语言**，
> 差别只有两处（见 §6）。根目录 `DESIGN.md` 仍然适用于 `apps/web` 与 `apps/miniapp`。

---

## 0. 这个应用是什么

一台离线运行的个人仪表：没有服务器、没有账号，复制进任何设备就能跑，
数据只在自己的机器上。它服务一个人——坐在桌前，对着一块 30 天 × 13 人的矩阵，
回答三个问题：**我今天什么班、这个月我加了多久、这个月我该拿多少钱。**

三条推论：

1. **主体是矩阵，不是页面。** 403 个格子之间的对比，比任何一段文字都重要。
2. **内容几乎全是班次代码和数字。** 人名和日期是标签。
3. **没有协作。** 登录/角色/同步/冲突都不存在，界面不为它们留位置。

---

## 1. 视觉基调：纸面 + 墨牌

参照物是**贴在墙上的排班表**和**值班室门口的牌子**。

- 底色是暖纸色 `--paper: #f4f4f0`，内容坐在纸面上，不用卡片阴影堆层级；
- 唯一的深色块是**值班牌**（`.plaque`）：它回答「现在/下一班是什么、还有多久、这个月几天」，
  视觉重量要压过下面所有内容；
- 分隔线是发丝线（`--rule: #dcdcd5`），只有强调线用 `--rule-strong`；
- 圆角只有两档：数据块 2px、纸张/卡片 12px。

**记忆点**：深色值班牌 + 左侧日历 + 右侧 30 列色块矩阵。

---

## 2. 颜色

班次色是唯一的语义色，其他一律灰阶。

| Token | 值 | 用途 | 文字对比度 |
|---|---|---|---|
| `--s-day` | `#e9a426` | 白班 | 8.4:1（墨字） |
| `--s-night` | `#2e3a75` | 夜班 | 9.5:1（纸字） |
| `--s-rest-cell` | `#c9d7c3` | 休息（日历 / 矩阵 / 姓名药片同源） | 4.9:1 |
| `--s-day-x` | `#92570a` | 白特 | 5.9:1 |
| `--s-night-x` | `#1a2150` | 夜特 | 11.1:1 |
| `--s-leave` | `#e9e8e2` | 事假 | 5.1:1 |
| `--ink` | `#14171a` | 正文 / 值班牌底 | 16.3:1 |
| `--ink-3` | `#62686e` | 次要文字 | 5.1:1 |

规则：

- **班次块必须上下左右都有 3px 缝隙**，不能连成一条色带（否则读不出「哪天换班」）；
- **休息也是色块**，浅绿 + 「休息」二字，不再留白——留白会被误读成「没排班」；
- 今天用 **2px 内阴影**（`inset 0 0 0 2px var(--ink)`）圈住，不用 `outline`：
  outline 画在盒外，落到小数坐标就会出毛边。

## 3. 排版

- 字体栈只用系统字体，**不加载任何网络字体**（`file://` 下离线可用是硬要求）；
- 字号阶梯：11 / 12 / 13 / 14 / 16 / 22 / 25 / 44px，全部整数；
- 行高统一 `calc(1em + 6px)`，保证在任何字号下都是整数像素；
- 字重只用 **400 / 700**（雅黑没有 600，写 600 会被合成假粗体、边缘发虚）；
- 不使用 `text-rendering: optimizeLegibility`（对中文是负优化）。

## 4. 结构

```
┌────────────────────────────────────────────────────────────┐
│ 昼夜  ‹ 10月 ›   09/20 – 10/19 · 30 天   …  统计 导出 导入 │  masthead
├────────────────────────────────────────────────────────────┤
│ 5月 6月 7月 … 12月                                          │  rail
├────────────────────────────────────────────────────────────┤
│ 下一班 白班 │ 距上班 8 小时 52 分 │ 本月 11白 9夜 10休       │  plaque
│ 10/19 08:00 开始 · 12 小时        │ ▁▁▁▁▁▁▁ (节奏条)        │
├────────────────────────┬───────────────────────────────────┤
│ 排班日历（点日期改班）  │ 全员排班  按班次 / 按姓名          │  board
│ 7 × 6 格              │ 13 行 × 30 列矩阵                  │
└────────────────────────┴───────────────────────────────────┘
```

- **值班牌**回答「此刻」，日历回答「这一周」，矩阵回答「整个月 + 谁和谁错开」；
- 日历与矩阵共享同一个格子语言（实色块 = 在岗），只是信息密度不同；
- 统计页在同一个版心里：`综合统计`（月度概览 + 加班分布 + 薪资计算）、`每日明细`。

## 5. 状态与交互

| 状态 | 表达 |
|---|---|
| 今天 | 2px 墨色内阴影 + 纸色数字 |
| 已手改 | 色块右上角 4px 纸色圆点（休息格用墨色 30%） |
| 法定节假日 | 日期下方红点（`.legal-dot`），农历/节日文字转红 |
| 加班 | 图例末位的「· 加班」；格子不加额外装饰，靠统计页核对 |
| 保存中 | 顶栏状态点 + 文案（`本地模式` / `已保存到本机`） |
| 出错 | `.error-banner`（警示底色 + 左侧竖条），不弹窗 |

改班走 `<dialog>` 抽屉（`.sheet`）：点遮罩/按 Esc 关闭，移动端从底部升起。

## 6. 与 Web 版的有意差异

| 差异 | Web | 本地版 | 原因 |
|---|---|---|---|
| 文字可选中 | 全局 `user-select: none` | `hover: hover and pointer: fine` 下 `text` | 桌面端要能复制工时/金额 |
| 版心 | `--page-max: 1560px`，居中留白 | `.app-shell { max-width: none }`，窗口撑满 | 离线版是「一个窗口一个应用」，两侧空 150px 没有意义 |
| 顶栏 | 跟随内容滚动 | 顶栏 + 月轨 `position: sticky` 冻结；统计页表头 + tab 同样冻结 | 桌面窗口里当标题栏用，滚走的标题栏会让人失去定位 |
| 滚动条 | 系统默认 | `scrollbar-width: none`（`html` 与 `.matrix-scroll`） | 那条灰槽会把「窗口」变回「网页」；滚轮/触控板/键盘滚动不受影响 |

实现放在 `src/styles/local.scss`，不污染共用层。

## 7. 验收

```bash
pnpm --filter shift-schedule-local run typecheck
pnpm --filter shift-schedule-local run test        # 62 个用例
pnpm --filter shift-schedule-local run build
node scripts/verify-dist.mjs                       # 36 项端到端（http + file://）
node scripts/screenshot-dist.mjs                   # 8 档分辨率布局断言 + 截图
```

`screenshot-dist.mjs` 的硬性检查：
表头与数据行列对齐、班次标签不溢出单元格、日历内容不被裁、
≥1440 整月无横向滚动、大屏宽度利用率 ≥70%、PC 可选中 / 移动端不可选。
